# Grayscale frame recordings

The camera module documents the [PGM recording format](../modules/camera/RECORDINGS.md)
used by `RecordedFrameSource`. The single-tag trial recorder writes this format
for paired front-camera images. See [single-marker tracking](FIDUCIAL_TRACKING.md)
for capture, session metadata and replay. Synthetic fixtures exercise the same
reader but do not establish headset camera accuracy.
